## 1. Ürün Vizyonu

### 1.1 Vizyon Cümlesi
> "Geliştiricinin kendi yönettiği, uzman AI çalışanlardan oluşan bir yazılım şirketi gibi çalışan; her çalışanın bir rolü, masası, uzmanlığı olan; görevleri görsel bir kanban üzerinde takip eden; öğrenilen bilgileri bağlantılı bir hafızada tutan; birden fazla AI motorunu (Claude Code, Codex, Gemini vb.) aynı anda koşturup orkestra edebilen desktop uygulama."

### 1.2 Farklılaşma
2026 ekosisteminde üç kategorideki araçlar (AI IDE: Cursor, Windsurf, Copilot; CLI: Claude Code, Codex, Gemini CLI, OpenCode, Aider; orkestrasyon: Claude Squad, Vibe Kanban, Conductor, Superset, Emdash, Nimbalyst, Capy, Composio AO) düz görev listesi/task panosu paradigmasında kalıyor. **AjanŞirket** ise:

| Paradigma | Mevcut araçlar | AjanŞirket |
|:---|:---|:---|
| Zihinsel model | Pair programming / araç kutusu | Şirket yönetimi (sen CEO'sun) |
| Metafor | Kod editörü / CLI | Ofis katı (ajanlar masasında) |
| Hiyerarşi | Tekil ajan veya düz takım | CEO → uzman roller, çift yönlü rapor |
| Bellek | Geçici context veya lineer not | Obsidian-vault + SQLite-graf (wiki-linkler, multi-hop) |
| Ajan özelleştirme | Config dosyası | Hire/Fire wizard'ı (rol, motor, zeka, bütçe, izin) |
| Ağırlık | Electron/TUI/Web | Tauri 2 + Rust (~5-12 MB kurulum, 80 MB RAM) |
| Çoklu motor | Tek veya kısıtlı | 10+ ilk dalga (Claude Code/Codex/Gemini/OpenCode/Aider/Cline/Kilo/Copilot/Cursor/Qwen) |
| Protokol | Çoğunlukla vendor-lock | Açık standartlar (MCP + A2A) |
| Tartışma | Paralel sonuçlar | Meeting/debat modu (Mixture-of-Agents) |
| Veri sahipliği | Bulut veya opak yerel dosya | Tam yerel vault + SQLite, Obsidian uyumlu |

### 1.3 Kullanıcı Personası
- Senior/Lead Developer ve Tech Lead
- AI-native üretim biçimini benimsemiş mühendis
- 2+ CLI kodlama ajanı kullanıyor ve aralarında koordinasyon ihtiyacı duyuyor
- Günde 4-8 saat kodlama ajanı ile çalışıyor
- Kendi "ajan ekibini" kurmak, yönetmek ve büyütmek istiyor
